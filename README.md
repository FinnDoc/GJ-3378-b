# Лабораторная №1 — API новостного портала (вариант 9)

Чтение новостей открыто. Создавать новости может любой вошедший пользователь, а менять и удалять — только свои.

## Как запустить

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python -m uvicorn app.main:app --reload
```

Открой в браузере:

- Swagger UI: http://127.0.0.1:8000/docs
- ReDoc: http://127.0.0.1:8000/redoc

Демо-аккаунт: логин `admin`, пароль `admin123`.

Если API уже запускали раньше и база есть, новые «учебные» новости сами не появятся. Удали файл `news.db` и перезапусти сервер — данные создадутся заново. То же нужно сделать после изменения структуры таблиц.

Ключ для подписи токенов берётся из переменной окружения `SECRET_KEY`. Если её нет, используется учебное значение из `app/security.py`.

## Эндпоинты

| Метод | Адрес | Кто может |
|---|---|---|
| GET | `/news` | все (гости видят только опубликованные) |
| GET | `/news/{id}` | все (черновик — только после входа) |
| POST | `/news` | после входа |
| PUT | `/news/{id}` | автор новости (полная замена) |
| PATCH | `/news/{id}` | автор новости (частичное изменение) |
| DELETE | `/news/{id}` | автор новости |
| GET | `/categories` | все |
| GET | `/stats` | все (гости — только по опубликованным) |
| POST | `/auth/register` | все |
| POST | `/auth/login` | все |
| GET | `/auth/me` | после входа |

Параметры списка `/news`: `category`, `q` (поиск), `sort_by`, `order`, `page`, `page_size`. Поиск и фильтр по категории не зависят от регистра, в том числе для русских букв.

Коды ошибок: `401` — не выполнен вход, `403` — попытка изменить чужую новость, `404` — новость не найдена, `422` — данные не прошли валидацию.
